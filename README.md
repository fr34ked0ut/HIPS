## How does it work?

Great question! It works by installing this into your browser. 

### Using Firefox?

Great. Follow these steps:
1. Open your browser.
2. Navigate to `about:debugging` in the URL bar.
3. Select `This Firefox`
4. Select `Load Temporary Add-on`
5. Choose the manifest in this reposistory at `dist/manifest.json`

### Using Chrome?

~~WOW...Judgement~~. Sure, we love RAM eating. Follow these steps:
1. Open your browser.
2. Go to `chrome://extensions/` in your url bar.
3. Select `Load unpacked`
4. Select the dist directory. That's it!

NOTE: If you're using something Chromium based, you may  need to search for the right steps... but most chromium based will be `<name of browser>://extensions` (e.g., `brave://extensions`, `edge://extensions`). Some may require developer mode to be toggled on.
